# Security Policy

## Supported Version

Security fixes are provided for the latest release of Sunny Mod Loader.

## Reporting

Do not attach untrusted Mod archives to a public issue. Report the affected Loader version, reproduction steps and
the smallest safe description of the archive structure through GitHub's private vulnerability reporting for this
repository. If private reporting is unavailable, open an issue without the archive and request a private channel.

The Loader accepts data-only Mod packages. A package that requires a DLL, executable, symbolic link or reparse point
is outside the supported format and should be treated as untrusted.
